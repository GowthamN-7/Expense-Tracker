# Smart Expense & Budget Tracker – MERN Stack Project

The Smart Expense & Budget Tracker is a full-stack web application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The main purpose of this project is to help users manage their daily expenses, monitor spending habits, and maintain a proper budget through an interactive and user-friendly dashboard.

This application provides a secure authentication system where users can register and log in using their email and password. After logging in, users can add, edit, delete, and manage their expenses efficiently. Each expense contains details such as expense title, amount, and category, allowing users to organize their spending records properly.

The project also includes a budget management feature where users can set their monthly income and budget limit. Based on the entered data, the application automatically calculates total expenses, remaining balance, total transactions, and top spending categories. If the expenses exceed the budget limit, the system displays a warning notification to alert the user.

To improve financial analysis, the application provides interactive charts and graphical visualizations, including expense analysis using line charts and category-based charts. These visual reports help users understand their spending patterns more clearly and make better financial decisions.

Additionally, the project includes a reminder section where users can set reminders for important payments or financial tasks. A PDF report generation feature is also implemented, allowing users to download and save their expense reports professionally.

The frontend of the application is designed with a modern fintech-style user interface using React.js, Bootstrap, and custom CSS styling. The dashboard contains a responsive sidebar navigation system, premium card layouts, analytics sections, and smooth user interactions to provide a professional user experience.

On the backend, Node.js and Express.js are used to create REST APIs for handling authentication, expense management, budgeting, and database operations. MongoDB is used as the database to store user and expense information securely.

Overall, this project demonstrates full-stack web development skills, CRUD operations, REST API integration, database management, responsive UI design, and real-time financial analytics using modern web technologies.
